Google Play Store Launch Android

1. Prerequisites

  • Google Play Developer account ($25 one-time fee) — play.google.com/console
  • A signed release APK or AAB (Android App Bundle)

2. Generate a Signing Key

keytool -genkey -v -keystore connecting-dots-release.keystore \
  -alias connectingdots -keyalg RSA -keysize 2048 -validity 10000
Store the keystore file and passwords securely — you cannot update the app without them.

3. Build the Release AAB

Add signing config to androidApp/build.gradle.kts:

android {
    signingConfigs {
        create("release") {
            storeFile = file("connecting-dots-release.keystore")
            storePassword = System.getenv("KEYSTORE_PASSWORD")
            keyAlias = "connectingdots"
            keyPassword = System.getenv("KEY_PASSWORD")
        }
    }
    buildTypes {
        release {
            signingConfig = signingConfigs.getByName("release")
            isMinifyEnabled = true
            proguardFiles(getDefaultProguardFile("proguard-android-optimize.txt"))
        }
    }
}

Then build:

./gradlew :androidApp:bundleRelease

Output: androidApp/build/outputs/bundle/release/androidApp-release.aab

4. Create the App in Play Console

  1. Go to All apps → Create app
  2. App name: Connecting Dots
  3. Default language: English
  4. App type: App, Free

5. Store Listing

  • Short description: Plan, prioritize, learn, and journal — all in one clean app.
  • Full description: Your productivity companion combining Kanban boards, daily planning, learning paths, journaling, and AI chat.
  • Screenshots: At least 2 phone screenshots (1080×1920 or similar)
  • Feature graphic: 1024×500 banner image
  • App icon: 512×512 high-res icon
  • Category: Productivity
  • Privacy policy URL: Link to this site's privacy-policy.html

6. Content Rating & Compliance

  1. Complete the content rating questionnaire (the app is suitable for all ages)
  2. Set target audience (13+)
  3. Complete the data safety form (Firebase Auth collects email; Firestore stores user data)

7. Upload & Release

  1. Go to Production → Create new release
  2. Upload the .aab file
  3. Add release notes
  4. Review and roll out to production (or start with internal/closed testing first)
First review typically takes 1–3 days. Subsequent updates are usually faster.

Apple App Store Launch iOS

1. Prerequisites

  • Apple Developer Program membership ($99/year) — developer.apple.com/programs
  • Xcode installed on macOS
  • The iOS app builds and runs on a simulator

2. Configure Signing

  1. Open iosApp/iosApp.xcworkspace in Xcode
  2. Select the iosApp target → Signing & Capabilities
  3. Select your team (Apple Developer account)
  4. Bundle ID: com.theultimatenote.app
  5. Xcode will auto-create provisioning profiles

3. Create App in App Store Connect

  1. Go to appstoreconnect.apple.com → My Apps → + New App
  2. Platform: iOS
  3. Name: Connecting Dots
  4. Primary language: English
  5. Bundle ID: com.theultimatenote.app
  6. SKU: connectingdots001

4. App Store Listing

  • Subtitle: Plan, Learn & Journal
  • Description: Same as Play Store
  • Keywords: kanban, planner, journal, productivity, todo, tasks, learning
  • Screenshots: Required for 6.7" (iPhone 16 Pro Max) and 6.1" at minimum
  • App icon: 1024×1024 (already in iosApp/iosApp/Assets.xcassets/AppIcon.appiconset)
  • Category: Productivity
  • Privacy policy URL: Link to this site's privacy-policy.html

5. Build & Archive

  1. In Xcode: Product → Destination → Any iOS Device
  2. Product → Archive
  3. Once archived, the Organizer window opens
  4. Click Distribute App → App Store Connect → Upload

Or from the command line:

cd iosApp
xcodebuild -workspace iosApp.xcworkspace -scheme iosApp \
  -destination 'generic/platform=iOS' \
  -archivePath build/iosApp.xcarchive archive

xcodebuild -exportArchive \
  -archivePath build/iosApp.xcarchive \
  -exportOptionsPlist ExportOptions.plist \
  -exportPath build/export

6. App Review Preparation

  • Provide a demo account (email + password) for the review team
  • Add notes about Firebase backend and any features requiring sign-in
  • Complete the App Privacy questionnaire (data collected: email, name, usage data)
  • Age rating: 4+ (no objectionable content)

7. Submit for Review

  1. In App Store Connect, select the uploaded build
  2. Fill in all required metadata
  3. Click Submit for Review
First iOS review typically takes 1–2 days. Apple may ask follow-up questions about data privacy or sign-in flows.
